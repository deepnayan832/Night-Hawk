WINDOWS INSTALLATION

Up and Running in 60 Seconds

NightHawk includes automated PowerShell scripts that handle Python virtual environments, local Three.js builds, and verification testing.

01

Clone Repository

Clone the source tree from GitHub to your Windows PC.

git clone https://github.com/deepnayan832/Night-Hawk.git
cd Night-Hawk
02

Automated Setup

Builds Three.js bundle, installs FastAPI & Uvicorn, runs 35 unit tests.

pwsh -File .\setup.ps1
03

Launch Application

Spins up local server on 127.0.0.1:8765 and opens browser UI.

pwsh -File .\start.ps1
