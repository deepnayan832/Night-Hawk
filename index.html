NightHawk is a planned desktop platform for wireless surveying, floor-plan-based RF analysis and 2D/3D coverage visualization. Turn measured signal readings into a clearer picture of your home's wireless environment.

Project status: The repository now includes a runnable Tier 1 Windows application under nighthawk-backend/. GitHub Pages hosts this static landing page only; the Python API and Wi-Fi scanner run locally on your Windows PC after setup.

Designed for real measurements

The project distinguishes measured data from simulated propagation and optional hardware experiments.

01 · Survey

Wi-Fi discovery

Inspect visible access points and supported adapter metrics such as RSSI, channel and link information.

02 · Plan

Floor-plan modelling

Represent rooms, walls, doors, windows, materials and router positions for spatial analysis.

03 · Visualize

2D / 3D coverage

Visualize collected measurements and modelled signal propagation with clear distinctions between the two.

04 · Optimize

Router placement

Compare candidate access-point positions and identify potential coverage gaps and interference.

05 · Experiment

Optional CSI sensing

Explore compatible ESP32 CSI streams for motion or presence research where supported.

06 · Privacy

Local-first approach

Designed to keep survey projects and diagnostics on the user's own machine rather than requiring cloud storage.

Hardware tiers

Tier 1 · Standard

Windows PC + Wi-Fi

Intended baseline for network discovery, adapter readings, floor-plan work and modelled coverage analysis.

Tier 2 · Optional

ESP32 CSI hardware

Additional compatible microcontrollers and firmware are required for CSI-based sensing. A normal router alone does not expose CSI data to Windows.

Tier 3 · Optional

Motorized scan rig

Specialized motion hardware is required for physical volumetric scanning. This is not a standard-router capability.
