About RSSI

Windows netsh usually exposes signal quality as a percentage. NightHawk converts that percentage to a rough dBm estimate and labels it as an estimate. It is not a calibrated hardware RSSI measurement. Nearby-network listing may require Windows Location access.

Interpretation

Measured map = IDW interpolation between saved survey points. Model map = free-space path loss plus per-wall material attenuation. The model does not include detailed antenna patterns, furniture, neighboring interference or calibrated material measurements.
